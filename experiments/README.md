# Experimentos

Cada análise relevante recebe um `experiment_id` e uma configuração versionada.

O registro deve apontar para:
- configuração;
- commit Git;
- manifests dos dados;
- séries/variáveis;
- parâmetros de embedding;
- método de Lyapunov/RQA/surrogates;
- status e notas.

Não apagar tentativas “que não deram certo”; elas ajudam a auditar escolhas analíticas.
